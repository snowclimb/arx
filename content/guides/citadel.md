Citadel lets players reinforce blocks instead of making them completely unbreakable. Reinforcement adds durability that an attacker must work through before the block is destroyed.

## Reinforcement materials

The official guide lists stone, iron and diamond as the main overworld reinforcement materials. `/reinforcements` shows the current values in game, so use that command rather than relying on old screenshots or remembered numbers.

## Useful commands

- `/ctr [group]` — enter reinforcement mode for already placed blocks while holding the reinforcement material.
- `/ctf [group]` — reinforce blocks as you place them.
- `/cti` — inspect reinforcement information by clicking blocks.
- `/reinforcements` — view current reinforcement materials and strengths.

## The important idea

Reinforcement is not invulnerability. It makes destruction expensive and slow, while NameLayer decides who can bypass or manage the reinforcement. In Arx, use the appropriate Arx group for public or shared infrastructure rather than reinforcing important state property personally.
